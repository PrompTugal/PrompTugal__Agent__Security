## Residuals: what it still does not do

1. **Code execution gets past the text checks.** This covers `bash -c`, `python -c`, `node -e`, a script the agent writes and runs, `xargs`, and `GIT_SSH_COMMAND` / `core.sshCommand`. The hook is a guardrail and an audit log, not a sandbox. The README says so.
2. **Working-tree rewrites that name no path are not stopped:** `git reset --hard`, `pull`, `merge`, `rebase`, `stash pop`, `apply`, tar and unzip.
   - The commit and push check keeps such a change from leaving the machine. A cloud session starts from a fresh clone.
   - A resumed local session in the same folder is covered only by the CI check below and by my review.
3. **R6, writing outside one's grant, stays observe.** It is logged, not blocked, until P11 and the open grants are decided.
4. **A relative Glob pattern that climbs out of the repository** (`../home/.ssh/*`) is allowed. It lists file names, not contents. Low.
5. **Coverage limits:**
   - A session whose settings do not load the kit is not covered.
   - Sub-agents' calls are not confirmed covered.
   - Each repository's copy can drift; my reviews compare their pinned hashes.

## Correction, 16:37 UTC (date -u): the pass is withdrawn until V3 is fixed

While reviewing kit v2.1 I found V3, and it applies to v2.0 (acc2f2a) as well. I missed it in the passes above.

- **The flaw:** the push check reads `git log HEAD --not --remotes`, not the ref being pushed.
- **How to reach it with ordinary git commands, no code execution:**
  - `git hash-object -w`, `git mktree`, `git commit-tree` and `git merge --ff-only` are all allowed. Together they make a commit on dev that removes the hooks, without ever running `git commit`.
  - Then, from a clean branch, `git push origin dev` is allowed. I tested this at acc2f2a, with a real bare remote.
  - The same push from dev itself is denied.
- **The fix:** check the local side of each refspec pushed, or the current branch when none is given. Also deny the plumbing that writes commits or refs (commit-tree, mktree, read-tree, update-index, merge or reset onto an arbitrary commit) when it touches a protected path. Or rely on the fixed push check alone, since every route out ends in a push.
- **The verdict:** P8 at v2.0 is NOT passed until this is fixed and re-tested. My message to Dinis via cl-6.conductor at 16:27 is corrected by this note.

## WITHDRAWN again, 16:54 UTC (date -u): the dffb673 pass does not hold (B1, B2 from cl-6.security@dinis)

cl-6.decisions@dinis relayed cl-6.security@dinis's no-pass (SovereignWebsite/Site__Agent__Security 61a729e). I tested both claims myself, in a throw-away install with signed v2 pins and a bare remote.

**At dffb673 (the head I passed):**
- **B1, confirmed.** A fake remote-tracking ref empties the push check, because "not on any remote" is read from the local refs/remotes. Then `git push origin dev` of a hook-removing commit is ALLOWED. The ref can be made with `git fetch . dev:refs/remotes/origin/x` or by writing it directly (`git rev-parse dev > .git/refs/remotes/origin/x`).
- **B2, confirmed.** The push check reads the session's project directory, not the clone the command acts on. `git -C <second clone> push origin dev` and `cd <second clone> && git push origin dev` are ALLOWED with a hook-removing commit in that clone.

**At f1a6953 (kit v2.2 at 10d27ed, policy v1.7.7):**
- B2 is fixed; both forms are denied.
- The `git fetch .` form of B1 is denied.
- **B1 is NOT fixed by a direct file write:** `git rev-parse dev > .git/refs/remotes/origin/x`, then `git push origin dev`, is ALLOWED.

**What fixes B1 at the root:** do not trust local refs/remotes. Before the push check:
- read the destination's real tip with `git ls-remote <remote> refs/heads/dev`;
- check `git log <ref> --not <that tip>`;
- if that tip is not in the local object store, check every commit reachable from `<ref>`, or deny.

Also protect `.git/refs/**` and `.git/packed-refs` against tool writes, owner none.

**Verdict:** my P8 pass of dffb673 is WITHDRAWN. Record 2026-11-26__abp-p8 stays suspended until cl-6.security@dinis and I both pass one head with B1 and B2 fixed and tested.
